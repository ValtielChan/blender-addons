# Color ID Map Generator

Bakes a Color ID texture per material from the UV islands, with a hue variation per face.

- Author: Muware
- Version: 1.1.0
- Blender: 4.5.0+
- Category: UV
- Location: View3D > Sidebar > **Color ID**
- File: `color_id_map_generator.py`
- Origin: Blender 4.5

## Installation
Edit > Preferences > Add-ons > Install, pick `color_id_map_generator.py`, then enable it.
