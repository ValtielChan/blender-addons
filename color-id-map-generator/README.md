# Color ID Map Generator

Génère (bake) une texture Color ID par matériau à partir des îlots UV, avec variation de teinte par face.

- Auteur : Muware
- Version : 1.1.0
- Blender : 4.5.0+
- Catégorie : UV
- Emplacement : View3D > Sidebar > Color ID
- Fichier : `color_id_map_generator.py`
- Provenance : Blender 4.5

## Installation
Edit > Preferences > Add-ons > Install, sélectionner `color_id_map_generator.py`, puis activer.
