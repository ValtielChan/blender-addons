# Low Poly Hex Tree

Procedural low poly tree with curved sections and box-projected UVs.

- Author: Muware
- Version: 1.4.3
- Blender: 4.2.0+
- Category: Add Mesh
- Location: View3D > Sidebar (N) > **Tree**
- File: `low_poly_hex_tree.py`
- Origin: Blender 5.1

## Installation
Edit > Preferences > Add-ons > Install, pick `low_poly_hex_tree.py`, then enable it.
